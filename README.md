# GS9 FOLDER

**GS9 FOLDER** is a lightweight, high-performance desktop shortcut hub built for Windows, designed with an exquisite frosted glass aesthetic, smooth animations, and native system integration.

## ✨ Key Features

* **Glassmorphism UI:** Features a frosted glass effect with deep backdrop blur, dynamic lighting gradients, and smooth transition effects.
* **Dual Theme Support:** Instantly switch between dark and light modes with smooth UI transitions and tailored system color variables.
* **Custom Icon Integration:** Effortlessly drop your custom images (`.png`, `.jpg`, `.ico`) into the hub folder to give your shortcuts a clean, customized look.
* **Drag & Drop Reordering:** Rearrange your shortcuts intuitively; custom layouts are saved automatically.
* **Local & Isolated:** Operates directly using your local application directory (`AppData\Roaming\disk-hub\HubFiles`) with zero external telemetry or tracking.
* **Frameless Native Window:** Custom-crafted frameless window with smooth resizing and native window controls.
